Updates to the Awesome Blueprints catalogue: new architecture blueprints for AI agents, RAG, MCP servers and infrastructure, and changes to existing ones.

2026-08-21

The catalogue opens

Forty-five free blueprints are available, covering FastAPI, PostgreSQL, Redis, Docker, GitHub Actions, vector search, streaming, MCP and LLM agents.

Every blueprint is one self-contained document. It states when to use the architecture and when not to, gives the reference implementation, the rules that matter and the failure modes, and ends with a definition of done. You can hand a single file to an AI coding agent and it has everything it needs — nothing points elsewhere for something you need.

Each one is written to be applied to a project that already exists. The agent is told to audit what is there before it proposes anything, and never to replace working code without asking you first.
